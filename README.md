# README: Консольное приложение для управления заданиями

## Описание
Данное консольное приложение представляет собой фреймворк для выполнения пользовательских заданий в интерактивном режиме. Программа позволяет создавать методы-задания, которые можно запускать через меню, и обеспечивает удобную навигацию между ними.

## Структура проекта

### Классы
- **Program** - Точка входа в приложение
- **Core** - Базовый класс, реализующий основную логику работы с методами и меню
- **StopStart** - Промежуточный класс, наследующий Core и предоставляющий публичный метод запуска
- **Methods** - Класс для размещения пользовательских заданий (наследуется от StopStart)

### Основные методы
- `Start()` - Запускает главное меню
- `stop()` - Останавливает выполнение текущего задания и возвращает в главное меню
- `menu(MethodInfo[] methods)` - Отображает меню и обрабатывает ввод пользователя
- `getMethods()` - Получает список всех методов класса Methods с помощью рефлексии

## Использование

### Добавление новых заданий
1. Откройте класс `Methods`
2. Создайте новый метод с модификатором `public`
3. В теле метода напишите код задания
4. В конце метода вызовите `stop()` для возврата в меню

Пример:
```csharp
public void zadanie4()
{
    Console.WriteLine("Мое новое задание");
    stop(); // Возврат в меню
}
```

### Запуск программы
1. Раскомментируйте строки в методе `Main`:
```csharp
StopStart stopStart = new StopStart();
stopStart.start();
```
2. Запустите приложение

### Навигация в меню
- Введите номер задания для его выполнения
- Введите `stop` для завершения работы программы

## Особенности реализации
- Использование **рефлексии** для динамического получения списка методов
- Обработка исключений при вводе данных
- Очистка консоли для улучшения пользовательского опыта
- Гибкая архитектура для легкого расширения

## Примечания
- Класс `Methods` наследуется от `StopStart`, что дает доступ к методам управления потоком выполнения
- Все методы в `Methods` должны быть публичными для обнаружения через рефлексию
- После выполнения задания вызов `stop()` обязателен для возврата в главное меню
