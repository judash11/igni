# README: Консольное приложение для управления заданиями

## Описание
Данное консольное приложение представляет собой фреймворк для выполнения пользовательских заданий в интерактивном режиме. Программа позволяет создавать методы-задания, которые можно запускать через меню, и обеспечивает удобную навигацию между ними.

## Структура проекта

### Классы
- **Program** - Точка входа в приложение
- **Core** - Базовый класс, реализующий основную логику работы с методами и меню
- **StopStart** - Промежуточный класс, наследующий Core и предоставляющий публичный метод запуска
- **Methods** - Класс для размещения пользовательских заданий (наследуется от StopStart)

### Основные методы
- `Start()` - Запускает главное меню
- `stop()` - Останавливает выполнение текущего задания и возвращает в главное меню
- `menu(MethodInfo[] methods)` - Отображает меню и обрабатывает ввод пользователя
- `getMethods()` - Получает список всех методов класса Methods с помощью рефлексии

## Использование

### Добавление новых заданий
1. Откройте класс `Methods`
2. Создайте новый метод с модификатором `public`
3. В теле метода напишите код задания
4. В конце метода вызовите `stop()` для возврата в меню

Пример:
```csharp
public void zadanie4()
{
    Console.WriteLine("Мое новое задание");
    stop(); // Возврат в меню
}
```

### Запуск программы
1. Раскомментируйте строки в методе `Main`:
```csharp
StopStart stopStart = new StopStart();
stopStart.start();
```
2. Запустите приложение

### Навигация в меню
- Введите номер задания для его выполнения
- Введите `stop` для завершения работы программы

## Особенности реализации
- Использование **рефлексии** для динамического получения списка методов
- Обработка исключений при вводе данных
- Очистка консоли для улучшения пользовательского опыта
- Гибкая архитектура для легкого расширения

## Примечания
- Класс `Methods` наследуется от `StopStart`, что дает доступ к методам управления потоком выполнения
- Все методы в `Methods` должны быть публичными для обнаружения через рефлексию
- После выполнения задания вызов `stop()` обязателен для возврата в главное меню





# README: Консольное приложение с динамической маршрутизацией заданий

## Описание
Данное консольное приложение представляет собой гибкую систему для выполнения пользовательских заданий с динамической маршрутизацией. Программа позволяет создавать отдельные классы для каждого задания и управлять ими через централизованное меню.

## Структура проекта

### Пространства имен
- **ConsoleApp1** - Основное пространство имен с реализацией заданий
- **jAC** - Вспомогательное пространство имен с интерфейсами и служебными классами

### Интерфейсы
- **Tub** - Определяет метод `Run(int i)` для выполнения заданий
- **Numbers** - Определяет методы `Start()` и `Stop()` для управления заданиями

### Основные классы

#### Lib (Библиотека управления)
- `Menu()` - Отображает главное меню и обрабатывает ввод пользователя
- `Run(int num)` - Запускает соответствующее задание
- `ToMenu()` - Возвращает пользователя в главное меню
- `Break()` - Завершает работу программы

#### Table (Таблица маршрутизации)
- `Run(int i)` - Маршрутизирует запросы к соответствующим заданиям через switch-case

#### Number1, Number2 (Задания)
- Каждый класс представляет отдельное задание
- `Start()` - Выполняет логику задания
- `Stop()` - Возвращает управление в главное меню

#### DI (Dependency Injection - закомментирован)
- Предназначен для динамического создания имен классов

## Использование

### Добавление новых заданий
1. Создайте новый класс в пространстве имен `ConsoleApp1`
2. Реализуйте интерфейс `Numbers` с методами `Start()` и `Stop()`
3. В методе `Start()` разместите код задания
4. В методе `Stop()` вызовите `lib.ToMenu()` для возврата в меню
5. Добавьте новый case в метод `Run` класса `Table`

Пример:
```csharp
public class Number3 : Numbers
{
    public void Start()
    {
        Console.WriteLine("Задание 3: вычисление факториала");
        // Ваш код здесь
        Stop();
    }
    
    public void Stop()
    {
        Lib lib = new Lib();
        lib.ToMenu();
    }
}

// В классе Table:
case 3: Number3 number3 = new Number3();
        number3.Start();
        break;
```

### Запуск программы
1. Запустите приложение
2. В главном меню введите номер задания для выполнения
3. Введите `stop` для завершения работы

### Навигация
- **Главное меню** - Отображается при запуске и после завершения каждого задания
- **Ввод номера** - Запускает соответствующее задание
- **Ввод "stop"** - Завершает программу

## Особенности реализации

### Архитектура
- **Разделение ответственности**: Каждое задание находится в отдельном классе
- **Интерфейсы**: Обеспечивают единообразие структуры заданий
- **Маршрутизация**: Централизованное управление через класс Table

### Обработка ошибок
- Проверка формата ввода (число или "stop")
- Защита от неверных номеров заданий

### Пользовательский опыт
- Очистка консоли для улучшения видимости
- Ожидание нажатия клавиши перед возвратом в меню
- Четкие подсказки для пользователя

## Сравнение с предыдущей версией

| Характеристика | Предыдущая версия | Текущая версия |
|----------------|-------------------|----------------|
| Структура заданий | Методы в одном классе | Отдельные классы |
| Маршрутизация | Рефлексия | Switch-case |
| Интерфейсы | Отсутствуют | Tub, Numbers |
| Гибкость | Высокая | Средняя |
| Простота добавления | Простое | Требует изменений в Table |

## Примечания
- Класс `DI` с методом `build()` закомментирован - предназначен для будущего расширения с динамическим созданием экземпляров
- Все задания должны наследовать интерфейс `Numbers` для единообразия
- Для добавления нового задания требуется модифицировать класс `Table`
